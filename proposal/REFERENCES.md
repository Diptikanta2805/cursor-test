# References and Verification Log

Every citation used in this package, with venue, volume, pages, DOI or URL, and
verification status. Each scholarly item was checked in August 2026 against Crossref,
the publisher page, or (where Crossref mismatched) OpenReview / the official
proceedings.

**Status codes**

| Code | Meaning |
|---|---|
| `VERIFIED` | Title, authors, venue, volume/issue, pages, and DOI confirmed against a registry or publisher record. |
| `PARTIAL` | Exists and is correctly attributed, but one bibliographic detail could not be confirmed from a registry record. |
| `PREPRINT` | Real and locatable, but not peer-reviewed in a journal issue. |
| `SOURCE` | Primary institutional or documentary source rather than a scholarly citation. |

## 2. Primary institutional sources

***Management Science* Code and Data Disclosure Policy.**
https://pubsonline.informs.org/page/mnsc/code-and-data-disclosure-policy — `SOURCE`.
Downloaders "will need to certify that the downloaded material will be used only for
verifying replicability of the paper's main results"; other research use requires
author permission. Reviewed August 2026.

**INFORMS Open Forum, "Management Science: May 2023" data-editor note.**
https://connect.informs.org/discussion/management-science-may-2023 — `SOURCE`.
Among papers with proprietary data, 30% provided at least sample or synthetic data
(35% in the then-most-recent year), because the Code and Data Editor more often
asked for it. These files are the dummy-CSV slot `doppel` standardises.

**Organization Science special-issue call, "AI-Enabled Frontiers in Organizational
Science."** https://orgsci.org/ — `SOURCE`. FAQ: "What if my data cannot be shared?"
Synthetic data may be appropriate if insights can be reproduced. "What if my
workflow depends on proprietary AI models?" Authors should select infrastructure
other researchers have a reasonable chance of accessing. Stage 1 criteria as
published include auditability; this package also scores stage of development as
requested for the workup.

**AEA Data and Code Availability Policy.**
https://www.aeaweb.org/journals/data/data-code-policy — `SOURCE`. Open licence
required; CC-BY 4.0 preferred for data, Modified BSD for code.

  already carry that lineage; we did not re-verify Rubin/Little independently in
  this pass and do not cite them in the proposal.
- **Nguyen et al. (2024), ICDM**, "Generating Realistic Tabular Data with Large
  Language Models" — real paper, not the GReaT citation. Dropped.
- **clawRxiv / non-publisher artifacts** — not used.
- Scorecard citations that appear only as "Wang et al. already wrote the methods
  note" are the 2025 *JBP* article above, not a second paper.
