# Diptikanta Panigrahi — Academic Portfolio

Personal website for **Diptikanta Panigrahi**, PhD Candidate in Strategic Management at the University of Kansas School of Business (Job Market 2026).

## Design Concept: The Strategy Observatory

An immersive academic portfolio that visualizes research as an interactive constellation — bridging a decade of industry digital analytics experience with strategic management scholarship on GenAI adoption, CEO cognition, and organizational innovation.

### Features

- **Interactive constellation canvas** — particle network responding to cursor movement in the hero
- **Research orbit system** — clickable nodes exploring five research streams
- **Animated typewriter taglines** cycling through research themes
- **Career timeline** — from Accenture analytics to KU strategic management
- **Publication showcase** — AOM Proceedings 2025 and working papers
- **Job market CTA** — prominent availability banner for 2026

## Local Development

```bash
# Serve locally (Python)
python3 -m http.server 8080

# Or with Node
npx serve .
```

Open [http://localhost:8080](http://localhost:8080)

## Deployment

This is a static site — deploy to GitHub Pages, Netlify, Vercel, or any static host:

```bash
# GitHub Pages: push to gh-pages branch or enable Pages on main
# Netlify: drag-and-drop the folder or connect the repo
# Vercel: vercel deploy
```
