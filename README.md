# Strategic Signals — Personal Academic Website

A distinctive portfolio site for **Diptikanta Panigrahi**, 4th-year PhD candidate in Strategic Management at the University of Kansas School of Business.

## Concept

**"Strategic Signals"** frames academic research as decoding signal from noise — mirroring the scholar's journey from digital analytics practitioner (Accenture, Grant Thornton) to strategy researcher studying generative AI adoption, CEO cognition, and organizational learning.

## Features

- Interactive network visualization hero (research concept constellation)
- Clickable research constellation with signal-strength indicators
- Scroll-driven career timeline ("Signal Path")
- Job market banner and materials request section
- Fully responsive, accessible, reduced-motion aware
- Zero dependencies — pure HTML, CSS, and vanilla JavaScript

## Quick Start

```bash
# Serve locally (any static server works)
python3 -m http.server 8080
# Open http://localhost:8080
```

Or open `index.html` directly in a browser.

## Deploy

This is a static site. Deploy to:
- **GitHub Pages** — push to `gh-pages` branch or enable Pages on `main`
- **Netlify / Vercel** — drag-and-drop or connect repo
- **KU personal hosting** — upload files to your web directory
